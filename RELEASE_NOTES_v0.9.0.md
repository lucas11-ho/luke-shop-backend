- Canonical storefront Experience Engine schema v2 fixes theme/template persistence and deterministic publish behavior.
- Adds 12 approved typography presets, including **iPhone / iOS System** using native Apple system font stacks. No Apple font files are bundled or redistributed.
- Adds expanded platform storefront template catalog and Platform Owner template create/update controls.
- Adds tenant-timezone promotion scheduling with DRAFT/SCHEDULED/ACTIVE/PAUSED/EXPIRED lifecycle support and schedule-window validation.
- Merchant order detail APIs now return only valid next order transitions.
- Adds public active scheduled-promotion feed for Customer Web.
